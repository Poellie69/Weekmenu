# Weekmenu IJmuiden

Plan meals from Sunday to Saturday, import recipes from any site, and make one shopping
list for Albert Heijn or Jumbo.

This repository is a Home Assistant add-on repository. To install:

1. In Home Assistant, go to **Settings → Add-ons → Add-on Store**.
2. Open the menu (⋮) at the top right, choose **Repositories**, and add
   `https://github.com/Poellie69/Weekmenu`.
3. Find **Weekmenu** in the store, click **Install**, and follow the steps on its Documentation tab.

The app itself lives in [`weekmenu/`](weekmenu/); see [`weekmenu/DOCS.md`](weekmenu/DOCS.md).
